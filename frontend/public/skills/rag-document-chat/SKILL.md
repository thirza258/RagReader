# RAG Document Chat Skill

Use RagReader's hybrid retrieval-augmented generation engine to ingest, search, analyze, and query document collections with verified citations.

## Capabilities

- Hybrid retrieval combining dense vector search and sparse BM25 indexing
- Multi-hop document querying and cross-passage reasoning
- Grounded citation generation and chunk attribution
- Interactive chat over ingested technical documents and reports
